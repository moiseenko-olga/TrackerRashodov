# 💸 Трекер расходов — Expense Tracker

Веб-приложение для учёта личных расходов на базе **Python + Flask + SQLite**.  
Позволяет добавлять расходы по категориям, следить за лимитами,
получать умные уведомления и формировать ежемесячные отчёты.  
Все данные хранятся локально на вашем компьютере — интернет не нужен.

## Быстрый запуск

### Вариант 1 — через .exe (только Windows, Python не нужен)

Дважды кликните на файл `TrackerRashodov.exe`.  
Браузер откроется автоматически на странице **http://127.0.0.1:5000**

> После запуска рядом с .exe появится файл `expenses.db` — это и есть ваша база данных.

### Вариант 2 — через Python (Windows / macOS / Linux)

**Требования:** Python 3.8+, Flask (`pip install flask`)

```bash
python app.py
```

Затем откройте браузер: **http://127.0.0.1:5000**

Для остановки нажмите `Ctrl+C` в терминале.

## База данных

Файл `expenses.db` — стандартная база SQLite. Открыть и посмотреть можно в:
- **DB Browser for SQLite** — https://sqlitebrowser.org (бесплатно)
- **DBeaver** — универсальный клиент

Схема таблиц и все 5 SQL-запросов находятся в файле `schema.sql`.

## FAQ
**Где хранятся данные?**  
В файле `expenses.db` рядом с `app.py`. Скопируйте его для резервной копии.

**Как сбросить данные?**  
Удалите `expenses.db`. При следующем запуске создастся новая БД с демо-данными.

**Поддерживается ли macOS / Linux?**  
Да. Flask работает на любой платформе с Python 3.8+.

**Можно ли открыть с другого устройства в сети?**  
В `app.py` измените `app.run(port=5000)` на `app.run(host='0.0.0.0', port=5000)`,
затем откройте `http://<IP-вашего-ПК>:5000` с другого устройства.
